# 仲良しCHAT 組み込み版

## 公開
元のサイトと同じ静的ホスティングに、このフォルダーの内容を配置してください。index.html と 404.html は両方更新します。CNAME と画像は元のままです。GitHub Pages では /chats への直接アクセスも 404.html 経由で開けます。ほかのホスティングでは /chats を index.html に書き換える設定を使用してください。

## 変更内容
- CHAT を /chats の通常ページに変更。チャット専用のモーダル・iframe・外部タブ入口を削除。
- ポータルの既存ナビ、色、グラス・ダーク表示を継承。
- 添付チャットのログイン・登録、スレッド作成、投稿、メッセージ削除、名前の色、時計・天気・地震・ニュースを移植。
- ID と JavaScript を分離して既存検索・設定との競合を防止。
- 既存サイト本体の welcome / instanceFrame 構造は維持しています。チャット内部には iframe を使用していません。

## 接続先
添付HTMLの既存API https://chat-api-companion.lovable.app をそのまま使用します。新しいサーバーやアカウント連携は追加していません。API 側で公開先オリジンの CORS 許可が必要です。API の稼働と公開先での実ログイン・投稿は別途確認してください。ポータルのログインとチャットのログインは統合していません。

/clear は元のコードと同じく入力欄だけを消去します。投稿履歴の全削除は実装していません。
